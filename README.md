# 蓝虎听歌（Tiger Music）· v1.0.0

免费全曲音乐应用：在线搜索 Internet Archive、Audius、Openverse 的完整曲目，导入本地音乐，同步歌词、收藏与歌单保存在本机。

## 下载

- Windows 安装版：https://github.com/lucianxiong/tigermusic/releases/download/v1.0.0/Tiger-Music-v1.0.0-setup.exe
- Windows 便携版：https://github.com/lucianxiong/tigermusic/releases/download/v1.0.0/Tiger-Music-v1.0.0-portable.exe
- 网页版：https://tigermusic.pages.dev/
- Android：GitHub Releases 中的 APK

## 开发

- 唯一源码：app/（Electron 与 Capacitor 仅作薄壳）
- 校验：npm run check
- 发布：npm run sync:all -- "提交信息"

工程规则见 AGENTS.md。
